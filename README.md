# Pomodoro Timer

A simple Pomodoro Timer web application built using HTML, CSS and JavaScript.

## Features

- 25-minute focus sessions
- 5-minute short breaks
- 15-minute long breaks after every four focus sessions
- Start, Pause and Reset controls
- Customisable timer settings
- Automatic session switching
- Sound notification when a session ends
- Completed focus session counter
- Settings and session count saved using Local Storage

## Technologies Used

- HTML
- CSS
- JavaScript
